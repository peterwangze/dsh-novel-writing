## 2. 重点评定：长手法重置 vs 简写偏差

**裁定：偏差成立且必要——Developer 判断正确。**

### 2.1 简写反噬的 CSS 层叠分析（核实）

`.nv-group`（client.js:3686）与 `.nv-bgroup`（:3691）同为单类选择器（特异性 0,1,0），注入同一 `<style>` 标签且 **`.nv-bgroup` 规则序在后**——同特异性下源序后者胜。因此若按任务书写简写：

| 任务书简写 | 层叠后果 | 被反噬的基底声明 |
|-----------|---------|----------------|
| `background: transparent` | 后序胜 → 覆盖基底 | `.nv-group` 的 `background:var(--dsw-alias-fill-l1,rgba(255,255,255,.04))`——**fill-l1 浅底丢失** |
| `border: none` | 简写展开含 border-left → 覆盖 | `.nv-group` 的 `border-left:2px solid accent`——**左缘 accent 条丢失** |
| `font: inherit` | 简写重置 font-size/weight/style/line-height 全部 | `.nv-group` 的 `font-size:12px`/`font-weight:600`——**字阶与字重崩坏** |

三项反噬论证全部成立。**长手法只重置基底未声明的面是唯一正确解。**

### 2.2 UA 默认面清理完备性（逐面核查）

`button` 元素 UA 默认 vs 本方案（作者样式恒胜 UA stylesheet，无需顺序考虑）：

| `border: 2px outset`（Chrome） | `.nv-bgroup` border-top/right/bottom:none（长手法）+ `.nv-group` border-left 覆盖左边 | ✅ accent 条保留 |

## 4. '@others' 哨兵零碰撞论证核实

**裁定：论证成立。**

- `normPath`（client.js:2022）保留 `/` 分隔符（仅统一+去尾+小写）→ **任何绝对路径归一化后必含 `/`**：Windows 盘符 `D:\x`→`d:/x`、UNC `\\s\sh`→`/s/sh`、POSIX `/x`→`/x`。
- 哨兵 `'@others'` 不含 `/` → 与任何绝对路径的归一化值**数学上不可能相等**。
- `@` 虽为 Windows/macOS/Linux 合法文件名字符（存在 `D:\@others` 这类合法路径），但其归一化值 `d:/@others` 含 `/`，仍不等于哨兵。碰撞唯一理论通道 = workspace.path 是无分隔符的相对路径且恰为 `@others`（含大小写/尾斜杠变体）——宿主契约中 workspace.path 为 pickDirectory/createDirectory/workspace.create 返回的**绝对根目录**（UX-005），通道封闭。
- 兜底：即便假想碰撞，后果仅为两组展开状态联动（可再点击分开），无锁死、无数据损坏——降级面安全。
- 源码注释留痕（client.js:2052）✓。
