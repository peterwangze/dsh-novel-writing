## 3. 新增风险（本次重点）：`rule()` 抽取口径放宽是否为静默假绿？

抽取值改宽（`rule('.nv-content h2', 'font-size:')`、`rule('.nv-content h3', 'font-size:')`）后，取值合规性交给 computed 断言。**实测结论：不是静默假绿，fail-closed 成立。** 副本变异证据：

| 变异 | 实测 | 说明 |
|---|---|---|
| **M2** h2 令牌 `--nv-fs-display`(20) → `--nv-fs-hero`(28) | **红：`headingScale`**（geometry exit=1） | 抽取仍成功，但 computed=28 ≠ 20 ⇒ 具名判据红；另有 smoke 令牌字面量断言双保险 |
| **M4** 删除 `.nv-content h3{font-size:...}` 规则 | **红：`rule not found`**（几何 exit=1） | 抽取期抛错 = fail-closed，不会静默跳过 |
| M1 `.nv-edwrap` 字号回退 15px | **红：`taTextW544`** | 见 F-1 |

**残余（P3-1）**：`rule()` 对同一选择器取**首个**含 mustHave 的规则。当前 `.nv-content h2` 只有一条含 `font-size:`（另一条只含 margin），无歧义；但若将来出现**第二条也含 `font-size:` 的覆盖规则**，抽取会取先出现者、而真实级联取后者 ⇒ 可能产生「注入了非生效规则」的镜像偏差。建议在 `rule()` 增加「同一选择器 + mustHave 命中数 ≤1」的断言，或取**最后一条**（与 CSS 级联同序）。
