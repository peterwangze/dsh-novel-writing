## 4. 新发现（非阻断）

- **P2-4（新）**：detail 拉取**失败**（overview 已就绪）时，四区分支内 CTA/新建章禁用且 `title` 为「章节数据未就绪」，但**该分支无「重试」入口**（`retryHome` 仅用于顶层加载支 `:4057`），用户只能等自动轮询；若接口持续失败则永久停在此态。建议同批补一个四区分支内可见的重试/刷新入口，或把禁用态文案区分「加载中」与「加载失败」。
- **P2-5（新）**：禁用态**标签**恒为「数据加载中…」，在「已失败」语义下略有误导（`title` 才写明「未就绪」）。建议标签按 `loading | failed` 两态二分。
- **P3-5（新）**：`.nv-home-row-name` 使用 `--nv-fs-reading`（16px，`:5628` 区域）。本步提前引入 reading 令牌本身合规（5 档内），但第③步会把正文 reading 统一为 16/1.9，注意不要在两处对同一令牌做不同口径的迁移。
