### 4. 测试忠实度（mini-react harness + 24 项断言 + 变异声明）

- **harness 语义与真实 React 比对**：`slot()` 游标 + 跨帧 `inst.hooks` 持久 ✅；`useState` 惰性 initializer 仅首帧求值 ✅；`Object.is` bail-out ✅（这正是「强制扳机」可被验证的前提，1512 行）；帧外 `setValue` → 同步 `drain()` 建模「调度一次重渲染」✅；`useEffect` 依赖比较 + 旧 cleanup 先行 ✅；`unmount()` 逐个跑 cleanup ✅；`useState` setter 的 `inst !== owner` 守卫建模卸载后 no-op ✅。
  **三处不忠实（均不构成本轮假阳性/假阴性，但须留痕）**：
  1. `sameDeps`（smoke.mjs:1498）把 `deps === undefined` 判为「相等 → 跳过重跑」，真实 React 语义是**无 deps 每帧重跑**——当前被审 hook 恒用 `[]`，未触达；复用该 harness 测其它 hook 时会失真（**F4（P3）**）。
