## 2. 根因与修复审查

R1 P2-1 根因复述：`lib/client.js` 中 `:root{...}` 是 JS **单引号字符串**，字体族写作 `\'Noto Serif SC\'`；旧 fixture 直接把源码片段拼进 `<style>`，CSS 把 `\'` 当成标识符内的引号字符，computed 族名成为 `"'Noto Serif SC'"`，匹配不到已安装字体而回退 generic。

修复审查（[L39-L63](../../scripts/verify-visual-geometry.mjs#L39-L63)）：

1. **按 JS 求值结果注入**：`rootMatch[1].replace(/\\'/g, "'")` 只做 `\' → '` 这一种确定性反转义；无 `eval`/`Function`（全文检索仅注释出现 “eval” 字样）。
2. **残余转义守卫（fail-closed）**：反转义后若 `rootCss` 仍含字面 `\'` 立即 `throw`（L46）。
3. **四族令牌语法守卫**：`--nv-serif` / `--nv-sans` / `--nv-kai` / `--nv-system` 必须存在；每个族名必须是合法单/双引号字符串或合法 CSS 标识符（允许空格/连字符），否则 `throw`（L49-L59）。
4. **prose 引用守卫**：`--nv-prose-family` 必须是 `var(--nv-serif|sans|kai|system)` 之一，否则 `throw`（L60-L63）。
5. 守卫都在 `rules`/HTML 构造与浏览器测量**之前**执行；非法输入会让门禁非零退出，而不是静默退化为旧行为。

审查者独立复算（不依赖脚本自报）：

```text
literal backslash-quote remains: false
--nv-serif  => 'Noto Serif SC','Source Han Serif SC','Songti SC',STSong,SimSun,serif
--nv-sans   => 'Noto Sans SC','Source Han Sans SC','Microsoft YaHei UI','Microsoft YaHei',system-ui,sans-serif
--nv-kai    => 'Kaiti SC',STKaiti,KaiTi,'Noto Serif SC',serif
--nv-system => system-ui,-apple-system,'Segoe UI','Microsoft YaHei',sans-serif
--nv-prose-family => var(--nv-serif)
eval present: false
```

说明：反转义后的 CSS **源码**用单引号引用族名（合法 CSS），浏览器 computed 序列化为双引号；任务口径中的「无 literal `\'`」指无**反斜杠转义残留**，本地复算为 false。R2 断言检查的是 computed `fontFamily` 是否含 `'` 字符，与旧缺陷签名精确对应。
