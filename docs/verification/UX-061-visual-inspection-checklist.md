## A. 主题矩阵（每项看明 + 暗）

| # | 检查 | 预期 | 失败判据 |
|---|------|------|----------|
| A1 | 亮色下表面/卡片是否可见 | 卡片有可见边界与层级 | 白底上「看不出卡片」 |
| A2 | 亮色卡片层级 | 书脊线（左 3px border-strong）+ hover 提边框；可辨不刺眼 | 完全分不出卡片与背景 |
| A3 | **hover 可感知性** | hover 时边框/前景变化可感知（accent 边框） | 只有极轻微底色变化 ⇒ 不达标 |
| A4 | 状态色文本可读性 | success/warn/error 文本在浅底 chip 上清晰 | 颜色发灰、与底色接近 |
| A5 | 主按钮文字 | 按钮文字与底色对比清晰（亮/暗都不「白字贴白底」） | 接近不可读 |
| A6 | **rail 明暗边界与实底按钮**（新增） | rail 与正文/章节列边界清楚；go(accent) / stop(err) 实底按钮在明暗两态都可读 | rail 糊进背景 / 实底按钮文字不可读 |

## B. 四视图（管理台 / 创作台 / 数据 / 发布）

| # | 检查 | 预期 |
|---|------|------|
| B1 | 管理台书目卡片 | 无渐变、无重阴影；书名 17/600 / meta 12 / 状态三层清晰；无 monogram 色块、改书脊线 |
| B2 | 创作台控制条 | **44px 竖向 rail**：状态 / 阶段徽标 / 开始停止 / 压缩上下文 / 绑定新会话，图标可辨、悬停有文字 |
| B3 | 数据面板标题 | 20px 且与数值形成层级 |
| B4 | 发布面板 | 状态与操作区层级清楚，无字号跳变 |
| B5 | 表单行高度配对 | 输入 32 / 按钮 29，**实测约 3px 高差**（min-height 是下限非精确值）；目检判定是否可见 |
| B6 | 固定宽控件换行 | `.nv-chip` / `.nv-csortbtn` / `.nv-wfchip` / 书卡 meta 不因 13→13.5、14→15 换行或截断 |
| **B7** | **rail 宽度挤出**（新增） | rail 44px 后章节列/正文未被压得过窄；窗口变窄时正文不横向滚动 |
| **B8** | **measure 行宽**（新增） | 正文 34em ≈ 510px（约 30–34 中文字/行）阅读节奏舒适；编辑区与阅读区行宽一致 |
| **B9** | **状态可感知性（失败即不通过）**（新增） | **不看 tooltip** 也能知道：当前工作流状态、是否未绑定、会话是否失效；busy 时能分辨「在跑」而非「卡住」 |
| **B10** | **章节选中态**（新增） | 左 2px accent 竖线 + 文字转主色，在明暗两态都足以辨认当前章 |
| **B11** | **书脊线多书辨识**（新增） | 多书列表里能快速定位目标书（书名 17/600 为主要识别符）；若扫描明显变慢 = 不通过 |
| **B12** | **数据表格**（新增） | 13px / 行高 26 / 仅横线：密度可读、不拥挤；severity 竖条清楚；mono 数值对齐 |
| **B13** | **竖排阶段徽标**（新增） | rail 内 vertical-rl 徽标字形正常（中文竖排无旋转错位）、可读 |
| **B14** | **busy 无动画感知**（新增） | 去循环动画后，静态点/图标 + 文案能表达「进行中」；与「卡住」可区分 |

## 失败时的最小定位材料

1. 截图（能看层级/字号/颜色/行宽关系即可）
2. 出错视图名 + 明/暗
3. 若涉及对比度：指出哪段文字（如「书卡状态文字」「告警 chip」）

> 处置口径：任一项失败 → 记录并在 plan-tracker 开修复项；**B9（状态可感知性）失败即不通过**；只有全部通过（或问题已登记且你接受）才可宣称 UX-061 视觉验收通过。
