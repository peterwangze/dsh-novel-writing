## 设计原则

1. 主题只换纸色、墨色、线条、朱砂/强调色；版式、字号、间距、布局、交互不变。
2. 不覆盖宿主 `--dsw-*`；不写 `color-scheme`；不伪造 `data-theme`。
3. 默认墨纸为暖纸 + 墨色 + 朱砂；青简为青绿纸 + 松墨；夜航为月白/靛青。
4. 顶栏入口是快捷键，设置页是管理面；两处共用同一选择、即时生效、即保存。
5. 真实数据优先：主题卡/预览不使用假书目或假对话；写作台仍是宿主原生会话抽屉。

## 设计板对照

- 浅色：墨纸 / 青简 / 夜航三列
- 暗色：同一套令牌的暗色档（不反色；纸色保持温度，朱砂降低亮度）
- 切换入口：顶栏菜单 + 设置页 3 卡 + 恢复默认
