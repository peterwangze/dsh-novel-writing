## 0. 事实基线（真机实测 1680×1050）

| 指标 | 现状 |
|---|---|
| `.nv-split` | 700px（占屏 42%） |
| **`.nv-content` 正文** | **236px（≈15 汉字/行）** |
| 文件树 / 章节列 / rail / 对话窗 | 240 / 160 / 44 / 700px |
| 字号分布 | 12px×124、13px×228、14px×98、15px×67 |

**宽度模型**（DR2 复算口径）：`colW = 视口 − 280（宿主侧栏）`；保留四栏时固定 chrome = 文件树 240 + 章节列 160 + rail 44 + 内边距 ≈20 = **464**。1680 → colW 1400；1440 → 1160；1366 → 1086。

## 1. P0-a 范围（本批唯一交付）

### A. 全屏工作台（可感知 #1）
- `.nv-split` 覆盖 `宿主会话区左缘 → 视口右缘`（colW 全宽）；resize 重算；复用 `findConversationRoot()` 几何探测（`client.js:3665`，不硬编码侧栏宽）。
- **对话窗折叠为右侧抽屉**：默认收起；右缘 **48px 唤出条**（图标 + `aria-label`/`title`「对话」）；点开为 **420px** 抽屉（z-index 920，介于 `.nv-split` 900 与 `.nv-console` 950 之间，DR2 附录 A 已核实可行）；开关状态 `localStorage` 持久化。
- **抽屉打开时的让位机制（D-2 收口）**：自动**收起文件树 240 + 章节列 160**（保留 44px rail），正文区让出 `420 − 44 = 376px`（抽屉覆盖 rail 44 + 正文 376）⇒ 文本列 = `min(544, colW − 44 − 376 − 24)`，**colW ≥ 988 时恒 544**。
- **恢复保证（P-6②）**：抽屉开启前对宿主对话窗原几何做快照（position/top/right/left/bottom/width/height/margin/zIndex/boxShadow/borderLeft/background，脚手架已原型 `restoreViewArea()`）；**关闭抽屉 / 切书 / 关闭工作台 / Esc / 刷新（经 localStorage）** 五路径全部走同一还原函数；还原后宿主对话窗与改造前逐属性一致。
- **宿主契约登记（P-6③，P-10）**：`lib/host-contract.mjs` item 3.3（layout-technique）在既有 margin/width 双压之外，补登记 `position/zIndex/boxShadow` 操纵面 + 48px 唤出条 DOM；smoke 补双向对账断言。
- 顶栏新增控件 **≤2**：`首页 / 写作` 切换、对话抽屉开关。
- 宿主对话组件本身零改动（拉出后输入/发送照常）。

### B. 任务流首页（可感知 #2）
- **打开工作台默认进入首页**；书卡网格降为「全部书籍」二级页（现有网格代码与状态保留）。
- **数据源（B-08 收口）**：overview（书名/阶段/已写字数/章数/最近更新/请求数，`lib/index.js:409-426`）**+ detail（最近章节的 published/gate/words/updatedAt、未发布章数、门禁未过项，`lib/index.js:615-626`）**，两源合一渲染（复用写作视图已有 detail 轮询，不新增服务端接口）。
- 四区（`.nv-home` 纵向、最大宽 880 居中、区间距 24px）：
  1. **当前书卡**：书名 20/600 + 阶段 chip + 已写字数（stat 18）+ 章数 + 最近更新；
  2. **今天写什么**：主 CTA「继续写第 N 章」（**高 36px**，accent 实底，唯一主按钮）；次按钮「新建章」「全部书籍」；
  3. **待办三项**：待处理请求数 / 未发布章数 / 门禁未过项——**点击目标（P-5⑥）**：前两项 → 对应视图（请求页签 / 写作视图发布区）；门禁项 → 写作视图并**滚动至第一个 gate 失败章**（无失败章则置灰不可点）；
  4. **最近章节**：最近 5 章（章号 + 标题 + 字数 + 时间）→ 点击进写作视图该章。
- **紧凑换书（P-5④）**：顶栏书名区 = 可点击下拉书单（1 次点击换书；现状从管理台换书需 2 次）。
- **显式移入 P1（P-5③⑤，防静默丢失）**：断更/存稿预警、首页数据信号入口 → §4 P1 首条。

### C. 正文可读性（可感知 #3）
- `.nv-content` / `.nv-edwrap`：`font-size: var(--nv-fs-reading)`（**新令牌 16px**）、`line-height: 1.9`（`--nv-lh-reading` 1.75 → 1.9）；`--nv-measure: 34em`（16×34 = **544px ≈ 34 汉字/行**）。
- **编辑态同步（DR3 N-1 裁决：选 (a) 统一）**：正文 `<textarea>` 内联样式（`client.js:2029`，现 `TYPO.body`/`TYPO.bodyLh` = 15/1.75）改为 reading 令牌（16/1.9）——阅读↔编辑切换无跳变；`smoke:1327` 精确串与 edwrap 绑定断言随第③步同 commit 迁移（迁移表 #15/#16）。
- **中文排版（本批第二件事）**：`.nv-content p{ text-indent: 2em; margin: 0 0 0.8em }`；标题不缩进。

### D. 字号契约（D-3 收口：只改两件事，不承诺全局层级）
- **本批字号改动只有两处**：①正文 15→16（`.nv-content`/`.nv-edwrap` 换用新 `--nv-fs-reading`）；②中文排版（缩进+段距）。**取消 12→13 UI 迁移**（`--nv-fs-base` 20 个消费点不动）。
- **修改面（新增/改动元素）允许字号集 = 5 档**：`--nv-fs-display` 20 / `--nv-fs-stat` 18 / `--nv-fs-reading` 16（新）/ `--nv-fs-ui` 13（新）/ `--nv-fs-base` 12。
- **存量档位白名单冻结**：11（caption）/11.5（内联）/13.5（card）/14（内联）/15（body 其余消费点）/17（display-s）/28（hero）本批一律不动；内联基线 `INLINE_FS_BASELINE` 不变（实现不得触碰内联字号）。
- 「全局字号种类 ≤5」**移入 P0-b**（三栏改造时随结构一并迁移）。

## 3. 视口阶梯（P0-a 四栏口径真值表，D-2 收口）

| colW 档（视口） | 抽屉关·文本列 | 抽屉开·文本列 | 机制 |
|---|---|---|---|
| **≥1008**（视口 ≥1288） | 四栏：`min(544, colW−464)` = **544** | 收导航（240+160）+ 让 376：`min(544, colW−444)` = **544** | 零遮挡 |
