# UX-063 重设计规格 v2（P0-a：全屏 + 任务流首页 + 可读性）

> **v2 依据**：`REVIEW-UX-063-SPEC-DR1 NEEDS_CHANGE / 10`（10 条阻塞逐条收敛）；DEC-156（用户裁决）；真机实测；`docs/research/UX-063-writing-app-layouts.md`。
> **v2 关键变化**：把原 P0 拆成 **P0-a（本批：最小可感知集合）** 与 **P0-b（三栏/检查器/抽屉/rail 退役，独立批次）**；几何按实数重算；补中文排版；补「并排截图 ≥5 处差异」硬闸门。

## 0. 事实基线（真机实测 1680×1050）

| 指标 | 现状 |
|---|---|
| `.nv-split` | 700px（占屏 42%） |
| **`.nv-content` 正文** | **236px（≈15 汉字/行）** |
| 文件树 / 章节列 / rail / 对话窗 | 240 / 160 / 44 / 700px |
| 字号分布 | 12px×124、13px×228、14px×98、15px×67 |

**DR1 关键论证（本规格采用）**：全屏后即使保留现状四栏，正文也会从 236px → 文本列 544px（2.3×）——**「正文一眼宽」不依赖三栏合并**，故三栏/分段/抽屉/rail 退役移出本批。

## 1. P0-a 范围（本批唯一交付）

### A. 全屏工作台（可感知 #1）
- `.nv-split` 覆盖 `侧栏右缘 → 视口右缘`（1680 屏 ≥1400px）；resize 重算；不硬编码宿主侧栏宽（复用现有探测）。
- **对话窗折叠为右侧抽屉**：默认收起；右缘 **48px 唤出条**（图标 + `aria-label`/`title`）；点开为 **420px** 抽屉；开关状态 `localStorage` 持久化。
- **抽屉不遮挡正文**：抽屉打开时正文区加 `padding-right: 420px`（文本列随之居中重排），任何视口下文本列 ≥480px 或自动收起左栏（阶梯见 §3）。
- 顶栏新增控件 **≤2 个**：`首页 / 写作` 切换、对话抽屉开关（顶栏总控件 ≤7，符合调研 ≤5+容错）。
- 宿主对话组件本身零改动（拉出后输入/发送照常）。

### B. 任务流首页（可感知 #2）
- **打开工作台默认进入首页**（首屏 = 四区，不再是书卡网格）；书卡网格降为「全部书籍」二级页（保留现有网格代码与状态）。
- 四区：
  1. **当前书卡**：书名（用现有 `TYPO.page`=20px，不新增档）+ 阶段 chip + 进度（**已写字数 / 章数 / 最近更新**；**不设「目标字数」**——全仓无该字段，DR1 B-08）
  2. **今天写什么**：主 CTA「继续写第 N 章」（accent 实底，唯一主按钮）；次按钮「新建章」「全部书籍」
  3. **待办三项**：待处理请求数 / 未发布章数 / 门禁未过项（可点击 → 对应视图）
  4. **最近章节**：最近 5 章（章号 + 标题 + 字数 + 时间）→ 点击进写作
- 首页布局契约（可机检）：`.nv-home` 纵向四区、最大宽 880px 居中、区间距 24px、书卡 20/600、CTA 32px 高。

### C. 正文可读性（可感知 #3）
- `--nv-fs-reading: 16px`；`.nv-content{font-size:var(--nv-fs-reading);line-height:1.9}`；`--nv-measure: 34em`（**16px × 34 = 544px，≈34 汉字/行**）。
- **中文排版（DR1 S-1 前移）**：`.nv-content p{text-indent:2em;margin:0 0 0.8em}`；标题不缩进。
- 编辑区 `.nv-edwrap` 同步 16px/1.9 与同 measure。

### D. 字体 5 档映射（可感知 #4，按 DR1 B-05 修正诚实表述）
| 档 | 值 | 现状哪些元素变 |
|---|---|---|
| reading | 16px | 正文 15→16（`.nv-content`） |
| h2 | 20px | 已合规（`TYPO.page`） |
| h3 | 18px | 原 17 若存在（**不用 17：与正文 1.06× 无感，DR1 指正**） |
| ui | 13px | 12→13 的 UI 文本（**明确列清单**，不宣称全量） |
| meta | 12px | 已合规 |

- **诚实口径**：现状 12/13px 占 68% 元素，本批**只改**「正文 15→16」与「明确列出的 UI 文本 12→13」；**不承诺「字号层级明显变化」**。可感知性由 A/B/C 三项承担。
- 幂等：`--nv-fs-{reading,h2,h3,ui,meta}` 五档必须被消费（未消费=0 守卫沿用）。

## 2. 验收判据

### 机检（`scripts/verify-visual-geometry.mjs` 扩展，--strict）
1. 1680 视口工作台宽 **≥1200px**
2. 正文文本列宽 ∈ **[512, 576]**（锚 544；上限按 36 汉字/行）
3. 字号种类 **≤5**；5 档令牌各 ≥1 消费者
4. 抽屉 420 / 唤出条 48 / 首页最大宽 880
5. 三视口 **1366 / 1440 / 1680** 下：正文文本列 ≥480 且**无横向滚动**
6. **抽屉打开后正文零遮挡**：文本列容器与抽屉矩形不相交（几何断言）
7. 既有守卫全绿：零幽灵令牌 / 对比度 / 未消费尺度令牌=0 / 内联字号 ratchet / CSS 字面量白名单 / 控件逐类名 / anchor FAIL=0

### 目检（用户）
1. **并排截图可无解释指出 ≥5 处结构差异**（DR1 要求的硬闸门；不足即不通过）
2. 打开即知「今天写什么」
3. 正文明显变宽（≈34 汉字/行）
4. 对话抽屉可拉出、不挡字
5. 明/暗两态层级清晰

## 3. 视口阶梯（P0-a 必须实现的行为）

| colW（工作台宽） | 左栏 | 正文 | 抽屉打开时 |
|---|---|---|---|
| ≥1240 | 240 | 544 | 正文区 padding-right 420，文本列仍 ≥512 |
| 1000–1240 | 240 | 480–512 | 正文区 padding-right 420，文本列 480（并临时收起左栏） |
| 760–1000 | 折叠为图标 | ≥480 | 抽屉覆盖，打开时提示可全屏 |
| <760 | 折叠 | ≥480 | 全屏建议态 |

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 全屏后对话不可见 | 48px 唤出条常驻 + 抽屉 + 持久化；宿主对话零改动 |
| 抽屉遮挡正文 | §3 阶梯 + 几何不相交断言 |
| 大改破坏守卫 | 迁移表逐条登记；rail/页签本批不动 ⇒ 风险面小 |
| 首页与写作状态不同步 | 共用同一 `overview` 轮询 |
| 「仍被判没提升」 | **并排截图 ≥5 处差异**闸门（本规格 §2 目检 1），不达标即返工本规格而非合并交付 |

## 7. 工作量

预估 **+250~400 行**（client.js）+ smoke 5~8 条断言 + geometry 4~6 条断言；远小于原 P0（+800~1250 行）。P0-b 另计。
