# UX-063 重设计规格（P0：全屏三栏 + 任务流首页）

**决策依据**：DEC-156（用户 2026-10-22 裁决）· 用户反馈「呈现感受没有大的提升」· 真机实测（见下）· 调研报告 [UX-063-writing-app-layouts](UX-063-writing-app-layouts.md)

## 0. 事实基线（真机实测，1680×1050）

| 指标 | 现状 | 问题 |
|---|---|---|
| `.nv-split`（工作台整体） | **700px**（占屏 42%） | 一半屏给了常驻对话窗 |
| `.nv-left` 文件树 | 240px | 展示 `00-work-type.md` / `06-chapter-outlines/` 原始文件名 |
| `.nv-chlist` 章节列 | 160px | 标题截断 |
| `.nv-rail` 图标条 | 44px | 竖排小字 |
| **`.nv-content` 正文** | **236px**（≈15 汉字/行） | **measure 34em 被容器钳死** |
| 字号分布 | 12px×124、13px×228、14px×98、15px×67 | 四栏全是小字，层级几乎无差异 |

**结论**：上轮（A+B）是「在错误结构上做精细装修」——令牌/对比度/±1px 字号不改变感知。

## 1. P0 目标（本批交付）

> 打开工作台 → 看见「今天该干什么」→ 一键进入写作 → 正文足够宽、层级清楚 → 检查器随手可用。

### 1.1 全屏工作台
- 工作台默认覆盖 `x = 侧栏宽 .. 视口右缘`（1680 屏下 ≥1400px），不再与对话窗各占一半。
- 对话窗折叠为**右侧抽屉**：默认收起，右缘保留 48px 唤出条（图标 + tooltip「对话」）；点开为 420px 抽屉，覆盖在检查器之上（不挤压正文）。
- 顶栏提供：`首页` / `全屏·并排` 切换 + 对话抽屉开关；状态持久化（下次打开记住）。

### 1.2 任务流首页（第一屏）
自上而下四区：
1. **当前书卡**：书名（20px/600）+ 阶段 chip + 进度（已写/目标字数、进度条）+ 最后更新
2. **今天写什么（主 CTA）**：`继续写第 N 章`（主按钮，accent 实底）· 次要：`新建章` / `查看细纲`
3. **待办**：待处理请求数 / 未发布章数 / 门禁未过项（三项可点击，直达对应检查器分区）
4. **最近章节**：最近 5 章（章号 + 标题 + 字数 + 更新时间），点击直接进写作视图
- 底部入口：`全部书籍`（打开管理台书卡网格——保留现有网格，作为二级页面）

### 1.3 三栏写作视图
| 栏 | 宽度 | 内容 |
|---|---|---|
| 左（可折叠） | 280px | 书名 + 章节列表（28px 行、左 2px 选中线、字数后缀）+ 搜索 + 底部「资料」入口 |
| 中（flex，正文） | ≥640px，measure 居中 | 正文 16px/1.9，`max-width: 34em`；编辑/预览切换；顶部章节标题 + 机审结果一行 |
| 右（检查器） | 320px | 分段控件：`工作流` / `数据` / `发布` / `请求`（替代现有 3 页签 + rail 按钮） |

- **rail 退役**：44px 图标条的内容并入顶栏（开始/停止、压缩上下文、绑定会话）与检查器（阶段徽标、状态文字）。
- **页签归零**：切换面从「3 页签 + rail」变为「右栏分段控件」，正文区永不被页签挤占。
- **文件树降级**：合入左栏底部「资料」抽屉（240px 覆盖层），默认不可见。

### 1.4 字体与层级（只保留 5 档）
| 用途 | 规格 |
|---|---|
| 正文 | 16px / 1.9（`--nv-fs-reading`） |
| 区块标题 H2 | 20px / 1.6 / 600 |
| 小标题 H3 | 17px / 600 |
| UI 文本 | 13px |
| 元信息 | 12px（`--nv-fs-base`） |

## 2. 验收判据（机检 + 目检）

**机检（`scripts/verify-visual-geometry.mjs` 扩展）**
1. 1680 视口下工作台宽 **≥ 1200px**
2. 正文容器宽 ∈ **[560, 800]px**（measure 生效，不再被钳制）
3. 字号种类 **≤5**（源码集合断言）
4. 章节行 28px、检查器 320px、对话抽屉 420px
5. 既有守卫全绿：零幽灵令牌 / 对比度 / 未消费尺度令牌=0 / 内联字号基线 / 几何基线 / anchor FAIL=0

**目检**
1. 打开即知「今天写什么」（不需要找）
2. 正文一眼宽（≥560px，约 30 汉字/行）
3. 主页/写作两屏之间切换 ≤1 次点击
4. 检查器四个分区不挤压正文
5. 明/暗两态下层级清晰

## 4. 风险与对策

| 风险 | 对策 |
|---|---|
| 全屏后对话不可见 → 协作中断 | 48px 唤出条常驻 + 一键拉出；会话功能零改动 |
| 三栏在小屏（<1200px）挤压 | 左栏/检查器自动折叠为图标/抽屉；断点 1200px |
| 大改破坏既有守卫 | 既有断言按新结构成组迁移（迁移表登记），不放宽 |
| 首页与写作视图状态不同步 | 单一 `overview` 轮询数据源，两屏共用 |
