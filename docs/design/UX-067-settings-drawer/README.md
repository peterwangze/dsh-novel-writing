# UX-067 设置页重构 + 原生会话抽屉视觉整合（用户 2026-11-09）

## 用户问题

1. **原生会话抽屉渲染不协调/异常**：工作台是暖纸面，右侧原生会话是宿主白色面板（顶部大块空白、composer 白、宿主蓝/白），像一块未主题化的外来面板。
2. **插件配置界面不协调**：插件设置仍是旧 inline 样式与暖纸卡片混在宿主白色设置对话框里；顶部一整段业务说明、字体选项只有选中项有边框、运行开关裸 checkbox、底部“启用插件”被截断，整体没有设置页的信息层级。

## 设计判断

- 会话抽屉是**宿主原生内容**，不能改业务/伪造消息；插件只做：
  - 宿主会话窗的**纸面作用域**（token 映射 + inline fallback，不依赖单一 `data-nv-theme` 属性）；
  - **抽屉外壳**（纸色侧栏、1px 缝、顶部/底部边界），让宿主内容成为“桌面上的协作侧页”，而不是白色空洞。
- 设置页位于**宿主设置对话框**，应服从宿主原生设置语言：中性表面、清晰分区、统一控件，不再把暖纸主题卡片直接铺在白框里；主题/字体只作为**预览样本**使用暖纸色。
- 两者都不改 API/数据/业务，不覆盖宿主 app 顶栏/左栏/对话框外壳。

## 设置页设计

### 页面骨架
- 标题区：小标签 `插件` + 标题 `小说写作` + 说明 `工作台外观、运行与诊断`；右侧状态 pill `已启用 / 已停用`。
- 正文最大宽约 760，居中；四块：
  1. **外观**
     - 主题卡：3 个主题 tile（墨纸/青简/夜航），中性卡面 + 小纸样预览；当前 border/✓；底部“当前：墨纸” + 恢复默认。
     - 写作排版卡：2×2 字体卡（每张显示自身字体的“文”样本 + 名称 + ✓），4 段字号 segmented control，预览行，当前值 + 恢复默认。
  2. **运行**
     - 启用插件（switch，描述 503 语义）
     - 工作台轮询（数字输入 + ms 后缀 + 500ms 下限）
     - 预设自动同步（switch）
     - API 允许 LAN 访问（switch + 开启时警示）
  3. **诊断**：默认折叠的“诊断信息（只读）”，展开复用 DiagnosticsPanel；不占首屏。
  4. **业务配置位置**：一条轻量 info 卡，指向管理工作台/发布页；不再用整段说明压顶。
- 统一控件：label 13、helper 12、section title 13/600、卡片 1px border/10 radius；所有字体选项有边界，选中用 accent ring；不使用旧 `TK` inline 样式。
- 表面：宿主设置对话框内使用中性表面（host `--dsw-alias-*` 兜底），主题/字体预览用 `--nv-*`；不再用暖纸大卡包整页。
- 底部 padding 足够，host 对话框自然滚动；不嵌套固定高度。

### 空/错误
- settings.describe 失败/无 ns 保留可读错误 + 重试；loading 用骨架/文本；不白屏。

## 会话抽屉设计

- 仍为宿主真实会话，420 侧栏；保持顶栏/状态栏可见。
- 纸面侧栏：
  - 左缘 1px rule + 8px soft shadow + paper-3 背景；与稿纸之间留 10–14px desk gap。
  - 宿主会话根/内容区/composer 使用 `--nv-*` 纸色 token；在 `viewArea` inline 设置宿主 `--dsw-alias-*` 兜底（覆盖 shadow/单一 attr 缺失），并在抽屉关闭时恢复。
  - 顶部大空白是宿主 hero 的空态；加一条 40px 的**插件抽屉标题带**（左侧 `协作 · 对话`，右侧 close/状态）以建立边界；不伪造消息。或使用宿主 header + 纸色作用域，避免双 header；若宿主 header 不可靠，插件标题带。
  - 关闭仍用 topbar 带文字「对话」；抽屉内 close 作为辅助，不新增第二个边缘手柄。
  - 窄容器 overlay 全幅；不压 paper。
- 主题 3 套浅深；composer/hero/header 无死白、死黑、宿主蓝。
- 无 fake 消息/差异/页码。

## 验收

- 1680 side + 1152/800 overlay 真实截图：抽屉是纸色侧页，宿主真实内容，顶栏/状态可见；无 1px 缝错位/遮挡。
- 设置页 1680/1152 浅暗 + 三主题：中性设置面，主题/字体预览可辨；字体选项全有边界；运行区 switch 一致；诊断折叠；无底部截断。
- 真实 settings.describe 读/写；Aa/主题选择仍即时；无 API/数据/旧键变更。
- 五门 + anchors + 真实探针；独立 AWN/0；用户目检。
