# 大纲审查

## 执行程序

按以下 12 步机械执行。每一步都必须产出书面结果。跳过任一步 = 审查无效。

### 第一步：加载文件

打开以下文件，确认全部可读取：
- `05-outline.md`
- `08-characters/main-characters.md`
- `08-characters/supporting-characters.md`
- `08-characters/character-relationships.md`
- `09-worldbuilding/world-settings.md`
- `09-worldbuilding/power-system.md`
- `17-continuity/story-bible.md`

### 第二步：数不可变更事实

1. 打开 `story-bible.md`，找到 `## 不可变更事实` 章节
2. 数条目数量 → 填入 `[___] 条`（要求 ≥5）
3. 逐条检查：每条是否有"违反后果"说明？→ 填入 是/否
4. 任一条无后果说明 → 扣 5 分

### 第三步：数伏笔

1. 打开 `05-outline.md`，找到 `## 伏笔设计` 表
2. 打开 `story-bible.md`，找到 `## 关键伏笔清单`
3. 数数量和字段完整性 → 填入 `[___] 个伏笔`（要求 ≥5）
4. 逐伏笔检查：是否有编号？是否有埋设章节？是否有最迟回收章节？是否有当前状态？→ 填入 是/否
5. 任一个伏笔缺字段 → 扣 3 分

### 第四步：检查时间线锚点

1. 打开 `story-bible.md`，找到 `## 时间线锚点`
2. 数节点数量 → 填入 `[___] 个`（要求 ≥3）
3. 逐节点检查：前后节点间是否有因果链？→ 填入 是/否
4. 任意两个节点间无因果链 → 扣 5 分

### 第五步：检查禁止偏离事项

1. 打开 `story-bible.md`，找到 `## 禁止偏离事项`
2. 数条目 → 填入 `[___] 条`（要求 ≥5）
3. 逐条检查：是否具体？（反例："不得无铺垫新增设定" ← 这是万金油，不合规）
4. 任一条为万金油表述 → 扣 3 分

### 第六步：检查主角成长弧线

1. 打开 `main-characters.md`，找到主角的 `### 成长线` 表格
2. 逐阶段检查：是否有起点状态？是否有转折事件？是否有目标状态？是否有触发事件？是否有代价？
3. 缺任一字段 → 扣 5 分

### 第七步：检查配角独立性

1. 打开 `main-characters.md`，找到每个主要配角
2. 逐个问：这个配角的动机是否独立于主角？（反例：动机是"帮助主角"=不合规）
3. 不合规配角数 → 填入 `[___] 个`
4. 每个不合规配角 → 扣 3 分

### 第八步：检查力量体系

1. 打开 `power-system.md`
2. 检查：每个等级是否有晋升条件？是否有资源消耗？是否有失败风险？是否有副作用？
3. 缺任一字段 → 扣 5 分
4. 检查：是否有"实力差距"量化说明？→ 无 → 扣 3 分

### 第九步：检查世界观自相矛盾

1. 打开 `world-settings.md`
2. 通读全文，标记任何自相矛盾的陈述
   （例：前文说"灵气极其稀有"，后文说"每个修士都有大量灵石"）
3. 矛盾数 → 填入 `[___] 处`
4. 每处矛盾 → 扣 10 分

### 第十步：检查盈利适配

1. 打开 `05-outline.md`，找到 `## 分卷大纲`
2. 每卷是否标注了建议的 VIP 上架位置？→ 填入 是/否
3. 未标注 → 扣 10 分
4. 付费起始章是否有理由说明？→ 无 → 扣 5 分
5. **付费卡点强度验证**（补充检查）：
   - 免费最后章：钩子是否足够强力，让读者"必须看下去"？□
   - 付费第一章：是否在开头 300 字内给出即时回报（解决悬念/释放爽点）？□
   - 付费后 3 章：爽点密度是否高于免费部分平均水平？□
   - 付费章节的"值回票价"感是否至少每章 1 处？□
6. **爽点商业价值检查**（对照目标平台）：
   - 起点：爽点是否能产生"停留 20 秒+"的沉浸感？
   - 番茄：爽点是否在每 800 字内出现以维持完读率？
   - 晋江：情感高潮是否足以引发评论区讨论？
7. 章末钩子密度：每章结尾是否预设了钩子类型？→ 是/否
8. 短剧/IP 适配：是否有强视觉冲突场景？是否可拆分为独立单元？→ 是/否
9. 每项不达标 → 扣 3 分

### 第十一步：检查差异化卖点

1. 打开 `05-outline.md` 或 `03-novel-info.md`
2. 用一句话写出"这本书和同类作品最大的不同" → `[一句话]`
3. 如果写不出一个具体的差异化锚点 → 扣 10 分
4. **套路化风险检测**（补充检查）：
   - 废柴逆袭开局（已过度使用，除非有强差异化角度）→ 风险
   - 退婚/被抛弃→复仇主线（套路化严重）→ 风险
   - 系统/面板流金手指（已泛滥，需有独特机制）→ 风险
   - "苟"字流命名（同质化最严重的标签）→ 风险
   - 纯打怪升级无世界观深度（难以竞争）→ 风险
   - 每命中一个套路化风险 → 扣 3 分
5. **跨界融合检查**：是否有跨界融合元素？（单一题材难以突围）→ 是/否
6. **熟悉-新颖平衡评估**（70% 熟悉 + 30% 未知 = 最优区间）：
   - 熟悉部分（读者立刻识别并信任的元素）：[列出]
   - 新颖部分（这本书独有的突破点）：[列出]
   - 比例严重失衡 → 扣 5 分

### 第十二步：检查群像生态

1. 逐个检查每个主要配角：
   - 是否有独立于主角的存在意义？（不只是"帮主角打架"或"被主角救"）
   - 是否有自己的动机/困境/成长？（哪怕只有一句话的设定）
2. 配角辨识度测试：如果遮住名字，读者能通过行为/对话区分每个配角吗？→ 是/否
3. 是否有至少 1 个配角可以独立支撑支线剧情？（这意味着 IP 潜力）→ 是/否
4. 反派是否有合理动机？（"纯粹的恶"只能有一个，其余必须有自己的逻辑）→ 是/否
5. 每项不达标 → 扣 3 分

### 第十三步：检查社会共鸣

1. 核心冲突是否触及读者已经在私下思考但无人公开言说的话题？
   （示例：《都挺好》触及原生家庭、《凡人修仙传》触及职场生存焦虑）
2. 作品的主题是否超越"打怪升级"，有更深层的表达？
   （不必说教，但要知道"这本书到底在讲什么"）
3. 主角的困境是否是当代读者能产生共鸣的困境？（而非纯粹虚构世界的困境）
4. 每项不达标 → 扣 5 分

### 第十四步：检查中段防崩设计（基于留存数据）

1. 中段（40%-60% 篇幅）是否有明确的冲突升级节点？
   （数据：40-60% 是中段弃书第二高峰，仅次于前 50 页）
2. 主角在中段是否从"被动应对"转为"主动出击"？（被动主角 = 弃书）
3. 中段是否引入了新的变量（新角色/新势力/新规则/新地图）？
   （当原有矛盾接近解决时，必须在解决前引入新变量）
4. 每项不达标 → 扣 5 分

### 第十五步：检查推荐触发点（基于传播心理学）

1. 是否规划了至少 3 个"Awe+Surprise"节点（读者会主动截屏/分享的段落）？→ 是/否
2. 是否设计了"你必须在场"的社交货币？（推荐这本书 = 显得自己有品味/有见识）→ 是/否
3. 是否存在"我想知道你是怎么想的"的讨论触发器？（引发评论区讨论的谜题/争议）→ 是/否
4. 每项不达标 → 扣 3 分

### 第十六步：检查回报分级

1. 是否在分卷规划中标注了每卷的回报分布？
   （格式：每卷末尾标注 `[小回报×N / 中回报×M / 大回报×1]`）
2. 大回报（卷末高潮）是否足够有力？读者读完这一卷会说"值了"？
3. 中回报间隔是否 ≤ 10 章？（连续 10 章无中回报 = 读者弃书高风险）
4. 小回报是否每 2-3 章至少 1 个？
5. 每项不达标 → 扣 5 分

### 第十七步：检查平台合规预检

1. AI 参与度预估：大纲阶段的 AI 使用是否在路径 A（平台安全）范围内？
2. 政策红线：是否涉及目标平台禁止的题材元素？
3. 原创性预判：核心创意是否有足够的差异化，不会被认定为"套路化"？
4. 每项不达标 → 扣 5 分
