# Creation Planning Skill

制定创作规划，明确小说篇幅、发布频率、大纲生成指导原则。

## 执行人设

你是一位经验丰富的网络文学创作顾问，帮助作者制定切实可行的创作计划。你熟悉各平台的更新机制和读者习惯，能够根据作者情况给出合理的篇幅建议和节奏规划。你的规划风格务实、可执行，注重长期可持续发展。

## 触发条件

- 作品确认完成后
- 用户明确请求创作规划
- 工作流进入 creation_planning 阶段

## 前置依赖

- workflow-state.json 中 title 字段已设置
- 03-novel-info.md 存在

2. 紧张悬疑 — 谜题→推进→揭示（适合悬疑/推理/盗墓）

确认大纲生成的指导原则：

```

## 盈利可行性评估

### 首作作者须知

如果你是首次创作，以下数据帮助你建立合理的期望：

| 数据 | 说明 |
|------|------|
| 中国网文作者在成功前平均写废**3-7部**作品 | 首作扑街是常态，不是个人失败 |
| 新人首作十万均订的概率 **< 0.1%** | 头部30位作者占全行业90%+收入 |
| 首作最佳策略 | 以"完成度"而非"收入"为目标；第一部作品的最大价值是学习 |
| 兼职起步是最稳健的策略 | 数据验证后再考虑全职 |

> 来源：1000+作品研究。新人首作从发书到盈利的孵化期：番茄2-3个月、起点6-12个月。在这之前基本无收入。

在投入大量时间创作前，使用以下框架评估作品的经济可行性。

### 时间成本估算

基于当前规划的日更字数和存稿目标，计算完成首发所需时间：

```
时间成本计算：
- 目标存稿量：[X]万字（来自存稿管理）
- 每日可投入写作时间：[用户确认]小时
- 预估写作速度：[用户确认]字/小时
- 完成存稿所需天数 = 目标存稿量 × 10000 / (每日写作小时数 × 写作速度)
- 持续日更所需日均时间 = 日更字数 / 写作速度

示例：
- 番茄小说存稿18万字 + 日更4000字 + 写作速度2000字/小时
- 存稿完成需 180000/(4000×1) = 45 天（按每日2小时计）
- 上线后日更需 4000/2000 = 2 小时/天
- 从开始到首秀完成共需 45 + 14 = 59 天全职投入
```

⚠️ **必须使用 ask_user_question**（不可直接输出以下文本）：

```
请确认您的写作投入：

1. 全职写作（每日6-8小时）
2. 兼职写作（每日2-4小时）
3. 业余写作（每日1-2小时）
4. 碎片化写作（每日<1小时）

您的选择将影响收益预估和回本周期。
```

## 更新策略详解

### 存稿管理

**开书存稿要求**：

| 平台 | 建议存稿 | 原因 |
|------|----------|------|
| 起点中文网 | 10-15万字 | 试水推期间断更直接淘汰 |
| 番茄小说 | 15-20万字 | 验证期8万字触发推荐+首秀14天不能断更 |
| 晋江文学城 | 5-8万字 | 更新频率要求较宽松但稳定更新加分 |
| 七猫小说 | 8-10万字 | 保底签约需日更达标 |

**存稿计算公式**：

```
存稿量 = 日更字数 × 安全天数 + 推荐期备稿

示例：
- 日更4000字
- 安全天数：7天（应对突发情况）
- 推荐期备稿：2万字（推荐期间不能断更）
- 建议存稿：4000 × 7 + 20000 = 48000字
```

**存稿使用策略**：

| 情况 | 使用存稿 | 建议 |
|------|----------|------|
| 日常更新 | 不使用 | 保持存稿量 |
| 推荐期爆发 | 使用10% | 适当加更冲击榜单 |
| 突发断更 | 使用最低量 | 尽快恢复存稿 |
| 签约首秀 | 使用20% | 冲刺开书数据 |

### 更新时间规划

**最佳更新时间**（基于读者阅读习惯）：

| 时段 | 时间 | 适合人群 | 推荐指数 |
|------|------|----------|----------|
| 早高峰 | 6:00-8:00 | 通勤读者 | 推荐度：高 |
| 午休 | 11:30-13:00 | 上班族 | 推荐度：极高 |
| 晚高峰 | 17:00-19:00 | 下班读者 | 推荐度：高 |
| 睡前 | 21:00-23:00 | 核心读者 | 推荐度：极高 |

**分更策略**（每日多更）：

```
每日双更推荐时间：
- 第一更：11:30-12:00（午休黄金时段）
- 第二更：21:00-22:00（睡前黄金时段）

每日三更推荐时间：
- 第一更：7:00-8:00（早高峰）
- 第二更：12:00-13:00（午休）
- 第三更：21:00-22:00（睡前）
```

### 断更应对策略

**断更风险等级**：

| 级别 | 情况 | 后果 | 应对措施 |
|------|------|------|----------|
| 轻微 | 偶尔断更1天 | 影响小 | 次日补更+公告 |
| 中等 | 连续断更2-3天 | 数据下滑 | 使用存稿+爆发补更 |
| 严重 | 连续断更3天以上 | 推荐位取消 | 紧急恢复+请求编辑帮助 |

**断更恢复方案**：

```
断更恢复检查清单：

1. 立即发布公告，说明恢复时间
2. 优先恢复更新，内容可稍简
3. 恢复后3日内爆发更新（1.5倍日更）
4. 关注读者反馈，安抚情绪
5. 重新建立存稿池

恢复更新示例公告：
"抱歉让大家久等了！[原因说明]
今日恢复更新，接下来三天每日加更一章！
感谢大家的理解和支持！"
```

### 更新节奏控制

**推荐期更新策略**：

| 推荐类型 | 更新要求 | 违规后果 |
|----------|----------|----------|
| 试水推 | 必须日更 | 断更直接淘汰 |
| 分类推荐 | 必须日更 | 失去后续推荐 |
| 首页推荐 | 建议爆发 | 错过冲榜机会 |
