# Genre Selection Skill

基于平台调研结果，分析热门和潜力题材，帮助用户选择合适的创作题材。

## 执行人设

你是一位资深的网络文学题材分析师，对各类题材的市场表现、读者喜好和创作难度有深入研究。你擅长识别红海中的机会和蓝海中的潜力，能够从新人作者的角度给出务实的建议。你的分析注重数据支撑，不妄下结论。

## 触发条件

- 平台选择完成后
- 用户明确请求题材分析
- 工作流进入 genre_selection 阶段

## 前置依赖

- workflow-state.json 中 work_type 字段已设置
- platform 字段已设置，**或** work_type 为短篇/小故事（可跳过平台调研）
- 若已执行平台调研：01-platform-research.md 存在；短篇路径可不存在该文件

## 执行流程

### 1. 加载平台信息

读取 `novel-project/workflow-state.json` 获取：
- 目标平台（platform 字段）
- 作品类型（work_type 字段）

**短篇路径处理**：
- 若 work_type 为"短篇小说"或"小故事/短篇集"，且 01-platform-research.md 不存在：
  - 跳过平台调研数据读取
  - 将平台设为"公众号/短篇平台"（或用户之前指定的发布场景）
  - 直接进入题材调研

- 若 01-platform-research.md 存在：读取该文件获取平台调研数据

**竞品分析消费**：
- 若 `novel-project/16-competitor-analysis.md` 存在（用户已完成竞品分析），读取其中的差异化定位和竞品空白分析
- 将竞品分析中的"竞品共性"和"竞品空白"结论注入题材推荐：
  - 竞品共性 = 该题材必须包含的核心要素，作为题材推荐的"基线要求"
  - 竞品空白 = 差异化机会，作为题材推荐的"差异化方向"
- 若该文件不存在（短篇路径或用户跳过竞品分析），正常进入题材调研

### 2. 执行题材调研

使用web_search搜索平台题材数据：

**动态日期获取**：搜索时必须使用当前年月，不硬编码年份。

**搜索关键词模板**（基于当前日期动态生成）：
- 长/中篇："[平台名称] {当前年份}年 热门题材 排行榜"
- 短篇："公众号短篇 {当前年份}年{当前月份}月 热门题材"、"短篇投稿平台 题材建议 {当前年份}"
- **盈利数据（必须搜索）**："[平台名称] [题材] 作者收入 {当前年份}"、"[题材] 网文 首订 均订 新人 {当前年份}"、"[平台名称] 各题材 收益对比 {当前年份}"

**示例**：如果当前日期是2026年3月，则搜索"起点中文网 2026年3月 热门题材 排行榜"（长篇）或"公众号短篇 2026年3月 热门题材"（短篇）

### 3. 分析题材类型

#### 红海题材分析

红海题材：竞争激烈但流量大

| 分析维度 | 内容 |
|----------|------|
| 热度排名 | 当前热门程度 |
| 竞争程度 | 作品数量、作者数量 |
| 成功案例 | 近期爆款作品 |
| 入门难度 | 新人突围难度 |
| 盈利潜力 | 基于 web_search 搜索的该题材平均首订/均订数据、新人作者收入范围、付费转化率方向 |
| 退款风险 | 该题材的退款率方向（高/中/低）及原因分析 |

#### 蓝海题材分析

蓝海题材：竞争小但潜力大

| 分析维度 | 内容 |
|----------|------|
| 增长趋势 | 读者增长速度 |
| 作品缺口 | 供需比分析 |
| 读者粘性 | 付费意愿、追更率 |
| 成功概率 | 新人成功案例 |

## 类型质量公约

选定题材后，基于1000+作品研究提取该类型的不可破规则，写入题材分析报告供后续阶段消费：

| 类型 | 不可破规则（违反=读者弃书） | 创新前沿（可突破的边界） |
|------|---------------------------|----------------------|
| 玄幻/仙侠 | 修炼进程必须清晰可见；主角必须持续变强；力量体系必须内部自洽 | 从等级制→序列制→扮演法的进化；力量代价化 |
| 言情/女性向 | HEA不可违背；情感亲密必须先于身体亲密；女主内心旅程不亚于爱情 | 谋生亦谋爱框架；霸道总裁→温柔守护者的进化 |
| 悬疑/推理 | 线索必须公平（读者与侦探有同等信息）；巧合不能是解谜核心；凶犯必须早期出场 | 不可靠叙述者+公平游戏的结合；社会派+悬疑的融合 |
| 科幻 | 硬SF：科学必须正确或合理外推，技术创造障碍非便利；软SF：思辨元素必须服务人性故事 | 硬/软边界模糊化；气候科幻成为新前沿 |
| 历史/权谋 | 世界必须真实可感；策略必须事后可解；个人与政治必须交织 | 爽文框架+深度主题的融合；喜剧化权谋 |
| 都市/现实 | 真实性不可妥协；平凡必须被赋予意义；苦难不能是无端堆砌 | 现实+类型的融合；知识碾压成为新爽点 |

> 选定的类型规则将随 workflow-state 传递给 quality-review，作为类型特定审查的基线标准。

## ⚠️ 高风险题材避坑指南

以下题材已被市场验证为"高风险"，新人作者应谨慎选择或完全避免。

### 必扑题材列表

#### 1. 慢热型文青文学（高风险）

**典型特征**：
- 前10章无明确主线
- 侧重心理描写 > 情节推进
- 大量环境描写和内心独白

**风险原因**：
- 网文读者普遍追求快节奏、爽感
- 文青风格与网文平台主流阅读期待不匹配

> 具体留存率和数据表现请通过 web_search 搜索 "[平台] 慢热文 数据表现 {当前年份}" 获取。

**替代方案**：如果喜欢深度内容，可以尝试"爽文皮+深度核"。

#### 2. 高认知门槛题材（高风险）

**典型特征**：
- 需要专业知识背景才能理解
- 大量术语和复杂设定

**高风险示例**：
| 题材类型 | 问题 | 改进方向 |
|----------|------|----------|
| 硬科幻 | 物理概念过于深奥 | 加入科普解释，降低门槛 |
| 专业职场 | 行业术语过多 | 用通俗语言替代专业术语 |
| 历史正剧 | 考据要求高 | 融入轻松元素，降低历史负担 |

> 具体完读率数据请通过 web_search 搜索获取，不使用预设数值。

#### 3. 政策高风险题材（随时面临下架）

**⚠️ 极度危险，强烈不建议尝试**

| 题材类型 | 政策红线 | 替代方案 |
|----------|----------|----------|
| 灵异鬼怪 | 不能出现具体鬼魂形象 | 改为精神疾病/人为阴谋/科幻解释 |
| 官场黑幕 | 严禁描写市级以上干部 | 只写村斗级别/架空世界观 |
| 校园暴力 | 反击尺度受限 | 改为智斗而非肢体冲突 |
| 涉政题材 | 敏感政治人物/事件 | 完全避免，改用架空设定 |
| 涉黄涉暴 | 过度描写性行为/暴力场面 | 适可而止，留白处理 |

#### 4. 情感代偿薄弱题材（读者代入困难）

**高风险示例**：
| 题材类型 | 问题 |
|----------|------|
| 中年危机 | 年轻用户无法共鸣 |
| 精英职场 | 与普通读者生活脱节 |
| 家庭伦理 | 短视频分流严重 |
| 纯悲剧 | 网文读者追求爽感 |

> 具体差评率、流量等数据请通过 web_search 搜索 "[题材] 网文 数据表现 {当前年份}" 获取，不使用预设百分比。

#### 5. 非虚构类内容（平台算法不适配）

非虚构类内容（诗歌集、散文随笔、人物传记、纪实文学）在网文平台天然获得较少推荐。

> 具体表现数据请通过 web_search 获取，不使用预设数值。

### 平台算法"隐形黑名单"

以下关键词可能触发限流：

| 类型 | 禁用词 | 安全替代 |
|------|--------|----------|
| 政治类 | 贪腐、政治斗争 | 职场竞争、商业博弈 |
| 敏感类 | 自杀、风水 | 觉醒、环境布局 |
| 宗教类 | 具体宗教仪式 | 虚构宗教设定 |
| 暴力类 | 详细暴力描写 | 侧面描写、一笔带过 |

### 题材风险评估表

```
题材风险评估检查：

□ 前三章是否有明确主线？
  - 是：安全
  - 否：高风险

□ 读者能否在5分钟内理解核心设定？
  - 是：安全
  - 否：认知门槛过高

□ 是否涉及政策红线？
  - 否：安全
  - 是：极高风险，强烈不建议

□ 目标读者群体是否明确？
  - 是：安全
  - 否：定位模糊风险

□ 是否有"爽点"？
  - 是：安全
  - 否：不符合网文核心需求

□ 题材是否符合平台主流？
  - 是：安全
  - 否：冷门风险（可能有潜力）
```

### 冷门但有潜力的题材

以下题材虽然冷门，但如果有独特角度可以尝试：

| 题材 | 潜力方向 | 注意事项 |
|------|----------|----------|
| 科幻 | 赛博朋克+社会议题 | 需要加入爽点元素 |
| 悬疑 | 悬疑+言情 | 节奏要快，悬念要强 |
| 体育 | 体育+成长 | 比赛描写要专业 |
| 医疗 | 医疗+职场 | 专业性强，需下功夫 |

**建议**：新人作者优先选择经过验证的主流题材，积累经验后再尝试冷门题材。
