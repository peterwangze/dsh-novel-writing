# Opening Optimization Skill

优化小说开篇前三章，应用黄金三章法则最大化读者留存和平台转化。

## 执行人设

你是一位资深的网文开篇优化专家，深谙各大平台的读者心理和审核机制。你擅长在3000字内完成人物立设、世界观渗透、冲突爆发三大任务。你的优化风格犀利直接，能够精准找出开篇的问题并提供有效的修改方案。

## 第一章：生死时速

### Contract-Clock-Crucible 三段式验证（基于1000+作品研究）

所有成功作品的开篇遵循此结构。第一章必须同时满足：

| 要素 | 要求 | 位置 | 检查 |
|------|------|------|------|
| **Contract（类型承诺）** | 读者在前300字内必须感知到本书的类型归属（玄幻/悬疑/言情/…） | 第1页 | □ |
| **Clock（时间压力）** | 主角面临一个有时间限制的困境、或风险正在升级中 | 前10% | □ |
| **Crucible（不可退出）** | 主角被框入一个无法简单退出的处境（身份/道义/生存迫使） | 前25% | □ |

> 数据支撑：番茄前200字无钩子=80%用户划走。起点前300字必须出冲突。
> 前50页流失44%的读者——这部份流失主要发生在前3章。

### 黄金开篇公式

```
环境异变 + 主角反常行为 + 致命威胁
```

### 结构要求

| 部分 | 字数 | 内容 | 技巧 |
|------|------|------|------|
| 钩子开篇 | 100-300字 | 制造悬念，吸引眼球 | 首段即爆点 |
| 人设速写 | 500-800字 | 用行动展现主角特点 | 反差标签 |
| 冲突引入 | 800-1200字 | 不可逆危机出现 | 外部威胁+内部困境 |
| 悬念收尾 | 100-200字 | 引向第二章的钩子 | 悬崖时刻 |

### 开篇必杀技

#### 1. 首段钩子设计

**三大钩子类型**：

| 类型 | 公式 | 示例 |
|------|------|------|
| 身份反差 | [异常身份] + [危险处境] | "当朝太子，此刻正跪在柴房里啃冷馒头。" |
| 环境异变 | [异常场景] + [生存威胁] | "红月当空，整座城市的人都消失了，只剩下他一个活人。" |
| 行为反常 | [反常行为] + [未知原因] | "他花光所有积蓄买下这座凶宅，只因为听到了奇怪的笑声。" |

**首段自检**：
```
首段是否在100字内：
- 出现异常事件？[是/否]
- 制造悬念？[是/否]
- 引发好奇？[是/否]
```

#### 2. 人设速写术

**冰山法则**：主角只展现10%的隐藏设定。

**人设速写技巧**：

| 技巧 | 说明 | 示例 |
|------|------|------|
| 行为展现 | 用行动表现性格 | "面对丧尸，他先找的是充电宝。" |
| 反差标签 | 制造人设反差 | "佛系杀手"、"社恐救世主" |
| 视觉锚点 | 独特的外在特征 | 异色瞳孔、机械义肢、宠物伙伴 |
| 非常态反应 | 出人意料的反应 | 危机当前先点外卖 |

#### 3. 冲突生成器

**冲突公式**：把"但是"作为核心词

```
主角获得[优势]，但是[致命限制]
主角觉醒[能力]，但是[严重代价]
主角遇到[机遇]，但是[道德困境]
```

**冲突类型**：

| 类型 | 说明 | 示例 |
|------|------|------|
| 生存压力 | 生命威胁 | "三日之内不完成试炼，必死无疑。" |
| 情感危机 | 重要之人受威胁 | "妹妹被带走，他必须去救。" |
| 能力觉醒 | 新能力的代价 | "每次使用能力，寿命减少三年。" |

#### 4. 章末悬崖

**悬崖时刻类型**：

| 类型 | 说明 | 示例 |
|------|------|------|
| 悬念型 | 未解之谜 | "他看到了那张脸——那是他自己的脸。" |
| 危机型 | 突发危险 | "门外传来脚步声，他无处可躲。" |
| 反转型 | 预期打破 | "她不是来救他的，是来杀他的。" |

### 第一章检查清单

```
第一章黄金检查：

□ 首段钩子
  - 100字内出现异常事件
  - 制造悬念，引发好奇

□ 人设立体

  - 设置反差标签

□ 冲突爆发

□ 章末悬念
  - 设置悬崖时刻
  - 引导向第二章

□ 避免雷区
  - 无大段世界观堆砌
  - 无环境描写超过200字
  - 无无关人物超过3个
```

## 第二章：世界观渗透

### 核心原则

**冰山法则**：只展示世界观的10%，90%隐藏。

### 结构要求

| 部分 | 字数 | 内容 | 技巧 |
|------|------|------|------|
| 承接上章 | 200-300字 | 回应悬念 | 平稳过渡 |
| 世界观渗透 | 800-1200字 | 用剧情带出设定 | 道具暗示 |
| 人物关系 | 500-800字 | 引入关键配角 | 三角模型 |
| 金手指预埋 | 300-500字 | 暗示主角潜力 | 爽点种子 |
| 情绪曲线 | 200-300字 | 波段节奏 | 危机-喘息-危机 |

### 世界观渗透技巧

#### 道具暗示法

不直接说明设定，通过道具暗示：

```
直接说明（错误）：
这个世界的修士分为练气、筑基、金丹三个境界，主角目前是练气期。

道具暗示（正确）：
他看了看手中的灵气检测仪，红色的"练气"两个字还在闪烁。修士工会发的说明书上写着：筑基期以上才能接取高级任务。
```

#### 悬念链设计

```
每800字设置微型悬念：
- 突然的震动
- 陌生来电
- 神秘人物出现
- 无法解释的现象
```

### 第二章检查清单

```
第二章黄金检查：

□ 世界观渗透
  - 是否自然，不堆砌
  - 是否用剧情带出
  - 是否只展示10%

□ 金手指预埋
  - 是否暗示主角潜力
  - 是否设置爽点种子

□ 情绪曲线
  - 是否有危机-喘息-更大危机
  - 情绪节奏是否起伏

□ 避免雷区
  - 无信息倾倒
  - 无设定超过500字
```

## 第三章：付费转化机关

### 核心任务

完成期待感爆破，促使读者付费追更。

### 结构要求

| 部分 | 字数 | 内容 | 技巧 |
|------|------|------|------|
| 能力显化 | 500-800字 | 主角能力初显 | 觉醒/突破 |
| 价值反转 | 500-800字 | 打破读者预期 | 反套路 |
| 关系网建设 | 400-600字 | 引入关键人物 | 三角模型 |
| 首战打脸 | 600-1000字 | 小高潮释放 | 爽点释放 |
| 认知颠覆 | 200-300字 | 章末反转 | 悬念炸弹 |

### 付费卡点技巧

**付费转化公式**：

```
能力觉醒 + 价值确认 + 悬念炸弹 = 付费转化
```

**认知颠覆类型**：

| 类型 | 说明 | 示例 |
|------|------|------|
| 身份颠覆 | 信任的人背叛 | "那个一直帮他的人，原来是敌人。" |
| 真相颠覆 | 之前的认知是错的 | "他不是穿越者，他是被抹去记忆的原住民。" |
| 能力颠覆 | 能力比想象中更强/更危险 | "这不是祝福，是诅咒。" |

□ 认知颠覆

## 常见开篇问题与修复

| 问题 | 症状 | 修复方案 |
|------|------|----------|
| 开篇太慢 | 前500字无悬念 | 加入首段钩子 |
| 人设模糊 | 读者记不住主角 | 添加反差标签 |
| 冲突不清 | 不知道主角要干什么 | 明确危机和目标 |
| 设定堆砌 | 大段世界观说明 | 用剧情带出设定 |
| 节奏拖沓 | 剧情推进太慢 | 删减无效描写 |
| 缺乏悬念 | 读者没有期待感 | 添加章末钩子 |
