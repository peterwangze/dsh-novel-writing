# Platform Research Skill

调研小说发布平台，分析热门题材、用户画像、盈利模式，为用户推荐合适的发布平台。

## 执行人设

你是一位资深的网络文学平台分析师，熟悉国内外主流小说平台的运营模式、分成机制和用户特征。你的分析客观、数据驱动，善于从盈利角度评估平台价值。你的报告风格清晰、条理分明，能为作者提供切实可行的建议。

## 触发条件

- 用户选择作品类型后
- 用户明确请求平台调研
- 工作流进入 platform_research 阶段

## 支持的平台

| 平台 | 类型 | 特点 |
|------|------|------|
| 起点中文网 | 付费阅读 | 男频为主，玄幻/都市热门 |
| 番茄小说 | 免费阅读 | 流量大，广告分成模式 |
| 晋江文学城 | 女性向 | 女频为主，言情/耽美热门 |
| 七猫小说 | 保底+分成 | 保底稿费，适合稳健创作 |

## 数据时效性提示

> 本 Skill 中的签约门槛、分成比例、推荐位规则、收益数据等内容为**历史参考值**。平台规则频繁调整，执行时必须通过 web_search 搜索当前平台最新政策，不应将 Skill 中的固定数值直接作为执行依据。
>
> 若 web_search 未能找到某项数据的官方来源，应明确标记"公开规则不充分，不应作强结论"。

## 合同陷阱避坑指南

### ⚠️ 签约前的关键提醒

签约是作者权益的核心环节，务必仔细审查合同条款。以下是新人作者最容易踩的坑：

> 以下合同条款示例中的具体金额（如违约金数额、分成比例等）仅为**说明性示例**，用于帮助理解陷阱模式，不代表任何平台的实际标准。签约前请以平台实际合同条款为准。

### 陷阱一：版权归属陷阱

**常见陷阱条款**：
```
"甲方（平台）享有作品的全部版权，包括但不限于复制权、发行权、
信息网络传播权、改编权等，永久性转让给甲方。"
```

**风险分析**：
- 一旦签约，作品后续影视改编、有声书、游戏等衍生权利全部归平台
- 作者失去对自己作品的所有控制权
- 后续无法自行运营电子书或其他版本

**避坑建议**：
| 权利类型 | 建议条款 | 说明 |
|----------|----------|------|
| 电子版权 | 可授权平台 | 核心权利，可适当让渡 |
| 有声版权 | 保留或分成授权 | 影视改编至少50%分成 |
| 影视版权 | 必须保留分成权 | 如版权卖800万，作者至少应得400万 |
| 海外版权 | 保留或分成授权 | 可授权但需保留收益权 |

**安全条款示例**：
```
"甲方授权乙方在授权期限内享有作品的独家信息网络传播权。
其他版权（包括但不限于影视改编权、有声版权、海外版权）
由甲方保留，或双方另行签订补充协议约定分成比例。"
```

### 陷阱二：收益分配陷阱

**常见陷阱条款**：

| 陷阱类型 | 示例条款 | 风险 |
|----------|----------|------|
| 定价陷阱 | "版税按图书定价的10%计算" | 书定价50元卖9.9元，作者只得0.99元/本 |
| 批发价陷阱 | "版税按批发价计算" | 批发价是定价的40%-60%，收入缩水一半 |
| 净价陷阱 | "版税按扣除成本后的净价计算" | 各种成本扣除后，作者几乎无收益 |
| 支付延期 | 未规定支付时间 | 平台可拖延支付，资金回笼慢 |

**避坑建议**：

```
收益分配检查清单：

□ 版税计算基数
  - 明确是"定价"还是"实际销售价"
  - 建议采用"定价"计算

□ 分成比例
  - 电子订阅：一般50%-70%
  - 影视改编：至少50%分成
  - 有声版权：一般50%分成

□ 支付周期
  - 明确每月/每季度结算时间
  - 逾期支付的违约责任

□ 数据透明
  - 要求查看销售数据
  - 要求提供收益明细
```

### 陷阱三：违约责任陷阱

**常见陷阱条款**：
```
"作者未按时交稿，需支付违约金1万元；
平台延迟出版，需支付违约金1000元。"
```

**风险分析**：
- 双方违约责任严重不对等
- 作者承担的违约风险远高于平台

**避坑建议**：
```
安全条款要求：

1. 双方违约责任对等
   - 作者违约金 = 平台违约金
   - 或都设置为合同总额的相同比例

2. 明确违约情形
   - 详细列出哪些情况算违约
   - 不可抗力条款必须包含

3. 解约金限制
   - 解约金控制在合同总额10%以内
   - 避免过高的解约成本
```

### 陷阱四：授权期限陷阱

**常见陷阱条款**：
```
"本合同有效期至作品著作财产权保护期届满为止。"
```

**风险分析**：
- 实际上是永久授权
- 作者终生无法收回版权

**避坑建议**：
| 授权类型 | 建议期限 | 说明 |
|----------|----------|------|
| 电子版权 | 5-10年可续约 | 保证作品长期价值 |
| 独家授权 | 3-5年 | 期满后可选择其他平台 |
| 改编授权 | 2-3年 | 期满后可重新谈判 |

### 陷阱五：修改权限陷阱

**常见陷阱条款**：
```
"平台有权对作品内容进行修改，无需作者同意。"
```

**风险分析**：
- 作品可能被篡改核心情节
- 影响作者声誉和作品口碑

**避坑建议**：
```
安全条款要求：

1. 修改需经作者书面同意
2. 核心情节和人物设定不可更改
3. 作者拥有最终审核权
4. 修改后的版本需作者确认后方可发布
```

### 陷阱六：终止条件陷阱

**常见陷阱条款**：
```
"合同签订后，任何一方不得单方解除合同。"
```

**风险分析**：
- 平台不履行义务，作者也无法解约
- 被绑定在不利的合同中

**避坑建议**：
```
必须包含的解约条款：

1. 平台未按时出版（如超过X个月）
2. 平台拖欠稿酬超过X天
3. 平台严重违约（如擅自修改作品）
4. 作品连续X个月无收益

保留单方解约权，设置合理的解约条件。
```

### 陷阱七：自动续约条款

**常见陷阱条款**：
```
"本合同到期后自动续约一年，除非作者在到期前30日内书面通知不续约。"
```

**风险分析**：
- 错过通知窗口期，合同自动延长，作者无法脱身
- 很多作者不记得在精确时间窗口内发送书面通知
- 平台可能"没收到"你的通知，但你没有证据

**避坑建议**：
```
1. 续约期前60天设置日历提醒
2. 书面通知必须使用可追踪方式（电子邮件已读回执/挂号信）
3. 合同中加入"双方均需在到期前X天书面确认续约，否则合同自动终止"
4. 拒绝单方面自动续约条款，改为双向确认机制
```

### 陷阱八：未来作品优先购买权

**常见陷阱条款**：
```
"作者在本合同期内及终止后五年内创作的全部作品，
平台享有优先购买权和独家签约权。"
```

**风险分析**：
- 你可能写了一本爆款，但不能带着它去其他平台拿更高价
- 平台可以"行使优先购买权"但只出很低的价，你还不能拒绝
- 实际上相当于用一本书的合同锁死了你未来五年的创作生涯

**避坑建议**：
```
1. 彻底删除"未来作品"条款
2. 如无法删除，限制为"同系列续作"而非"全部作品"
3. 时间限制缩短为合同期+1年（而非5年）
4. 平台行使优先权必须在收到offer后30日内匹配同等条件，否则失效
```

### 陷阱九：竞业限制条款

**常见陷阱条款**：
```
"合同终止后12个月内，作者不得在任何竞争平台发布作品。"
```

**风险分析**：
- 你离开平台后一年内不能在任何地方写作赚钱
- "竞争平台"定义过宽，可能覆盖所有写作平台
- 这是对作者生计的直接封锁

**避坑建议**：
```
1. 彻底删除竞业限制条款
2. 如无法删除，要求按竞业期支付补偿金（通常为原合同月均收入的50%-100%）
3. 将"竞争平台"明确定义为排他性列举，而非宽泛描述
4. 竞业期限制在3个月以内
```

### 陷阱十：广告权与内容修改权

**常见陷阱条款**：
```
"平台有权在作品中插入广告、进行编辑修改以符合平台规范，
无需另行通知作者。"
```

**风险分析**：
- 你的作品可能被插满广告，阅读体验被破坏，但你只能看着
- "编辑修改"可以延伸到修改情节、人物、结局
- 广告收入全部归平台，你一分钱都拿不到

**避坑建议**：
```
1. 广告插入需经作者书面同意，并明确广告收入的作者分成比例（建议50%+）
2. 修改仅限于错别字和格式，不得涉及情节、人物、结局
3. 任何修改需经作者书面确认后方可发布
4. 作者有权要求移除有损作品形象的广告
```

### 陷阱十一：独家授权范围过广

**常见陷阱条款**：
```
"作者授予平台在全球范围内的独家、永久、不可撤销的全部版权。"
```

**风险分析**：
- "独家"被定义为不能在任意平台以任意形式发布——包括你自己的公众号
- 你用自己的笔名在不同平台写作也可能被认定为违约
- "全球范围"意味着海外翻译权也被锁死

**避坑建议**：
```
1. 独家授权限定为"中国大陆地区简体中文电子版权"
2. 明确排除：作者在自己社交媒体的非商用发布、实体出版、海外翻译
3. 独家期结束后全部权利自动回归作者
4. 作者保留以相同笔名在其他平台创作不同类型作品的权利
```

### 签约检查清单

```
签约前必查清单：

□ 版权归属
  - 明确哪些权利授权，哪些保留
  - 避免永久性转让

□ 收益分配
  - 版税计算基数明确
  - 分成比例合理
  - 支付周期明确

□ 违约责任
  - 双方责任对等
  - 违约金合理

□ 授权期限
  - 有明确的到期时间
  - 可续约而非永久

□ 修改权限
  - 修改需作者同意
  - 保护作品完整性

□ 终止条件
  - 有明确的解约条件
  - 保留单方解约权

□ 自动续约
  - 检查是否有自动续约条款
  - 拒绝单方面自动续约，要求双向确认

□ 未来作品
  - 检查是否有优先购买权/独家签约权
  - 如无法删除，严格限定范围和期限

□ 竞业限制
  - 检查是否有竞业限制条款
  - 如有，要求支付竞业补偿金

□ 广告权
  - 检查是否有广告插入权/内容修改权
  - 广告收入分配是否明确

□ 独家范围
  - 检查独家授权的具体地域和权利范围
  - 是否保留海外翻译、实体出版、社交媒体发布权

□ 争议解决
  - 明确仲裁或诉讼地点
  - 避免只对平台有利的条款
```

### 各平台签约模式对比

| 平台 | 主要签约模式 | 特点 | 新人建议 |
|------|--------------|------|----------|
| 起点中文网 | 分成签约 | 版权归属作者，收益分成 | 适合新人，风险低 |
| 番茄小说 | 分成签约 | 广告分成模式 | 适合新人，门槛低 |
| 晋江文学城 | 签书不签人 | 作品签约，作者自由 | 较友好 |
| 七猫小说 | 保底+分成 | 保底签约需日更达标，保底千字价格因作品而异（需搜索最新政策）；保底期通常为3-6个月，到期后转为纯分成；平台可能在保底期内终止合作（需注意合同终止条款） | 保底提供收入下限，但需注意：保底期后的分成收入可能大幅下降；合同中可能包含单方面终止保底的条款 |

**新人签约建议**：
1. 优先选择分成签约，保留版权
2. 保底签约要注意版权条款
3. 买断签约谨慎考虑，版权一次性转让
4. 签约前最好咨询专业人士或律师
