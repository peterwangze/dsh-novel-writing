# Competitor Analysis Skill

对同赛道头部作品进行深度拆解，提取成功要素，制定差异化竞争策略。

## 执行人设

你是一位资深的网文市场分析师，擅长从成功作品中提取可复用的方法论。你能够从章节级别拆解一部作品的成功要素：爽点分布、钩子设计、节奏曲线、付费转化点。你的分析风格精确、可操作，注重"能学到什么"而非"好不好看"。

## 触发条件

- 平台调研完成后、题材选择前执行（标准流程，为选题提供差异化参考）
- 大纲生成前（帮助设计爽点和节奏）
- 作品表现不佳时（对标分析差距）
- 用户明确请求竞品分析

## 前置依赖

- 平台已确定
- 01-platform-research.md 存在（题材候选方向可暂时为空，将在本阶段完成后进入题材选择）

## 执行流程

### 1. 竞品选取

使用web_search搜索同赛道头部作品：

**搜索关键词**（动态日期）：
- "[平台] [题材] {当前年份}年 热门排行榜 TOP10"
- "[平台] [题材] 完本精品 高收藏 {当前年份}"
- "[平台] [题材] 新书 爆款 {当前年月}"
- "[题材] 网文 成功案例分析 {当前年份}"

**竞品选取标准**：

| 类型 | 数量 | 选取标准 |
|------|------|----------|
| 头部标杆 | 2-3部 | 同题材同平台 TOP3，学习天花板 |
| 中腰部成功 | 2-3部 | 近半年新书中数据较好的，学习可复制路径 |
| 同期竞品 | 2-3部 | 近1-3月开书的同题材作品，了解直接竞争 |

⚠️ **必须使用 ask_user_question**（不可直接输出以下文本）：

```
基于[平台][题材]，推荐以下竞品进行分析：

头部标杆：
1. 《[书名]》 - [简要数据：收藏X万/均订X]
2. 《[书名]》 - [数据]

中腰部成功：
3. 《[书名]》 - [数据]
4. 《[书名]》 - [数据]

近期新书：
5. 《[书名]》 - [数据]

是否同意这些竞品？
1. 同意，开始分析
2. 替换某部作品
3. 添加我关注的作品
```

对每部竞品进行宏观层面分析：

```markdown

### 基本信息
- 作者：[作者名]
- 平台：[平台]
- 题材：[题材]
- 字数：[字数]万字
- 状态：[连载中/已完本]
- 收藏：[数据]
- 评分：[数据]

### 核心卖点
1. [卖点1]
2. [卖点2]
3. [卖点3]

### 读者画像
- 核心读者：[描述]
- 读者最爱什么：[基于评论分析]
- 读者最讨厌什么：[基于差评分析]

### 商业表现
- 付费数据（如可查）：[数据]
- 衍生开发：[有声书/漫画/短剧等]
- 成功指标：[具体表现]
```

### 3. 公开信息深度分析

> ⚠️ AI 无法访问小说正文全文。以下分析基于 web_search 可获取的公开信息（书评、读者讨论、平台公开数据、作者访谈等）。

**搜索关键词**：
- "《[书名]》 书评 分析 {当前年份}"
- "《[书名]》 读者评论 优缺点"
- "《[书名]》 爽点 节奏 分析"
- "《[书名]》 作者 创作谈 访谈"

**分析模板**：

```markdown
## 公开信息分析：《[书名]》

### 读者反馈分析
基于书评区/讨论区/社交媒体的读者评价：

**读者最喜欢的要素**：
1. [要素1] - 来源：[URL]
2. [要素2] - 来源：[URL]

**读者最常吐槽的问题**：
1. [问题1] - 来源：[URL]
2. [问题2] - 来源：[URL]

### 成功要素推测
基于公开信息推测的成功要素（非基于原文拆解）：

| 要素 | 推测依据 | 可信度 |
|------|---------|--------|
| [要素1] | [依据：读者评论/排名数据等] | 高/中/低 |
| [要素2] | [依据] | 高/中/低 |

### 可借鉴方法论
基于公开信息提取的方法论（标注推测程度）：

1. **[方法1]**：[描述] — 📌 基于：[来源]
2. **[方法2]**：[描述] — 📌 基于：[来源]

> ⚠️ 以上分析基于公开信息推测，非基于原文逐章拆解。实际创作时需结合自身阅读体验验证。
```

### 数据诚实性要求

- **禁止虚构**："爽点分布图"、"节奏曲线"等需要逐章阅读原文才能生成的内容，如果 AI 无法实际阅读，必须明确标注"无法生成，需作者自行阅读分析"
- **标注推测**：所有非直接来源的结论必须标注"推测"
- **鼓励用户自行阅读**：建议用户亲自阅读竞品前30章并记录爽点/钩子，AI 可提供记录模板

### 4. 差异化定位

基于竞品分析，制定差异化策略：

```markdown
## 差异化定位分析

### 竞品共性（必须有）
这些是同赛道成功作品的共同要素，我们也需要：
1. [共性1]
2. [共性2]
3. [共性3]

### 竞品空白（机会点）
这些是现有作品没有覆盖或做得不好的：
1. [空白1] - [我们可以如何填补]
2. [空白2] - [我们可以如何填补]

### 我们的差异化卖点
基于竞品空白，我们的独特定位：
1. [差异化卖点1] - [具体描述]
2. [差异化卖点2] - [具体描述]
3. [差异化卖点3] - [具体描述]

### 风险评估
- [差异化可能带来的风险]
- [应对策略]
```

## 搜索失败处理

若 web_search 无法获取某竞品的公开信息：

```
AI: 抱歉，无法获取[作品名称]的公开信息。

可能原因：
1. 网络连接问题
2. 搜索服务暂时不可用
3. 该作品公开信息较少
```

⚠️ **必须使用 ask_user_question**（不可直接输出以下文本）：

```
确认处理方式：

1. 重试搜索
2. 使用通用分析框架（不含具体数据，仅提供分析维度）
3. 跳过此竞品，分析其他作品
4. 手动输入竞品信息
```

## 注意事项

- 竞品分析是"学习"不是"抄袭"
- 提取方法论，不是复制情节
- 差异化是成功的关键，不能做同赛道的低配版
- 竞品分析应定期更新，市场在变化
- 分析完成后的方法论应融入到大纲和细纲设计中
