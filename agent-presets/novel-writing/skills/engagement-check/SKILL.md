# 阅读体验审查

独立审查正文的文学质量、情感体验和读者留存驱动力。

## 执行 Agent

`writing-workflow/agents/engagement-reviewer.md`

## 执行程序

### Step 1：加载文件

- `07-content/chapter-XXX.md`（正文）
- `06-chapter-outlines/chapter-XXX.md`（细纲——钩子强度承诺）
- `workflow-state.json`（情感签名定义）
- `17-continuity/continuity-ledger.md`（前 4 章情感履约记录）

### Step 2：执行硬门禁（4 项）

```
□ [11] CCC 三要素（仅1-3章）？       检查结果：[通过/不通过] → [通过/阻断]
□ [12] 连续 3 章弱钩子？             检查结果：[是/否] → [通过/阻断]
□ [14] 连续 5 章情感签名偏离？       检查结果：[是/否] → [通过/阻断]
□ [15] 连续 10 章无中回报？          检查结果：[是/否] → [通过/阻断]

通过/阻断：___/4
```

**CCC 三要素激活条件**：仅第 1-3 章激活。
- Contract（契约）：章节开头是否建立了读者预期？
- Clock（时钟）：是否在 10% 处设置了时间压力或风险升级？
- Crucible（熔炉）：是否建立了不可退出的处境？

**钩子交付验证**：细纲承诺的钩子强度 vs 正文实际交付 → 未交付 = 阻断。

### Step 3：文学质量检查

逐项检查写作质量：

```
□ 句式多样性：无连续 3 句以上相同结构？[是/否]
□ 感官描写丰富度：感官描写 > 60%（非抽象概括）？[是/否]
□ 对话自然度：口语化对话 > 80%（非书面化）？[是/否]
□ 视角一致性：同一场景内无无故视角跳跃？[是/否]
□ 文风稳定性：全章文风一致？[是/否]
```

### Step 4：情感体验检查

```
□ 情绪曲线：本章是否有起伏（非平直）？[是/否]
□ 期待感：读者是否有"想知道接下来发生什么"的驱动力？[是/否]
□ 代入感：读者是否能通过主角视角体验事件？[是/否]
□ 爽点质量：爽点是否有铺垫→引爆→余韵的完整结构？[是/否]
□ 情感签名履约：本章传递的情感是否与定义的情感签名一致？
  - 定义的主情感：[来自 workflow-state]
  - 本章实际传递：[检测结果]
  - 连续偏离章数：[滚动计数]（≥5 = 阻断）
```

> 数据支撑：情感契约是读者付费的核心原因——读者付费不是为了看"发生了什么"，而是为了体验"我期待的某种情感"。

### Step 5：维度评分（2 个维度，18 分）

| # | 维度 | 满分 | 得分 | 扣分理由 |
|---|------|------|------|---------|
| 6 | 文学质量 | 8 | | |
| 7 | 情感体验 | 10 | | |
| **小计** | | **18** | **[___]/18** | |

**维度 6 细则**：句式多样、感官描写丰富、对话自然、视角一致、文风稳定

**维度 7 细则**：情绪曲线有起伏、期待感强度、读者代入感、爽点释放质量、情感签名履约

### Step 6：输出报告

```markdown
# 阅读体验审查报告 — 第X章

## 硬门禁结果
- CCC：[通过/不通过/N/A]
- 弱钩子连续：[是/否]
- 情感偏离连续：[是/否]
- 无中回报连续：[是/否]

## 文学质量
- [逐项结果]

## 情感体验
- 情感签名履约：[一致/偏离]
- 连续偏离：[X]章

## 维度评分
- 文学质量：[X]/8
- 情感体验：[X]/10
- 小计：[X]/18
```
